## Points à lever avant réutilisation en RAG

- **Ma16 :** aucune fiche exacte retrouvée. L’étiquette 24 V ne donne pas un budget électrique complet.
- **Th03 :** HTU21D et SHT21 restent deux hypothèses; la fiche du composant ne valide pas les entrées de la carte GY-21.
- **Ce01 / Th02 :** contrôler les variantes Pi et identifier le SSD/adaptateur. **Th04 / Th07 :** fabricant, matière ou puissance restent inconnus.
- **Ma09 / Ma10 / Ma12 / Ma13 / Ma14 / Ma15 :** conserver les limites de variante et de module; ne pas confondre une ressemblance avec une référence exacte.
- **Ma11 :** une valeur commerciale Cortex A8 sur la page ELEGOO est incohérente; elle n’est pas reprise dans les données techniques du projet.
- Les notices web non téléchargées ont un chemin local nul; le portail CH340 doit encore livrer son PDF. Les plans mécaniques peuvent être graphiques et demander un OCR ou une vérification visuelle.
- Les PDF **HTU21D / TE** et **MAX7219 / Analog Devices** ont été ouverts dans l’outil web mais n’ont pas pu être archivés localement : réponse HTTP 403 pour TE et expiration de téléchargement pour Analog Devices, y compris après nouvel essai. Leurs URL et ces échecs restent dans le catalogue.
- Les extractions automatiques ne restituent pas fidèlement tous les tableaux, courbes et schémas. Citer URL, document, page et niveau de correspondance; bloquer une réponse de câblage si la référence exacte manque.
- Les PDF restent la propriété de leurs éditeurs. Vérifier leurs licences avant republication ou usage dépassant le corpus de travail interne.
