# Scripts utilitaires

- `python scripts/validate_contract.py` : vérifie la structure des événements de démonstration (contrat FP-LAB-1.1).
- `python scripts/ingest_docs.py` : indexe ou ré-indexe la documentation technique dans ChromaDB (`--reset` pour vider et reconstruire).
- `python scripts/query_rag.py` : client interactif en ligne de commande pour tester et interroger le serveur RAG (MCP) ou le moteur local direct.
